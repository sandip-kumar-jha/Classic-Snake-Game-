🐍 Snake Game – JavaScript

📌 Project Description :

This is a simple Snake game built using HTML, CSS, and JavaScript.
The game starts when the user presses any arrow key and the snake moves continuously.

This project is created for learning JavaScript logic and practice.

🛠️ Technologies Used :

1)HTML

2)CSS (Grid Layout)

3)JavaScript

🎮 How to Play :

1)Press any arrow key to start the game

2)Use arrow keys to control the snake direction

3)Eat food to increase score

4)Avoid hitting walls or snake body

🎯 Features:

1)Snake movement using keyboard

2)Random food generation

3)Score calculation

4)Collision detection (wall & self)

5)Game over and restart logic.

🧠 Game Logic (Simple Explanation) :

1)Snake position is stored using an array

2)Food position is generated randomly

3)Snake moves based on key press direction

4)When snake eats food, body length increases

5)Game ends if snake hits wall or itself.

📂 Project Structure

├── index.html

├── style.css

├── script.js

└── README.md

🚀 How to Run the Game :

Download or clone this repository

Open index.html in any browser

Press arrow keys to start playing
